# Glosario Cato Parking

**Codigo documental:** CP-GOB-003  
**Version:** 1.0  
**Estado:** Borrador para validacion institucional  
**Fecha:** 2026-07-17

## Proposito

Establecer una definicion oficial unica para los terminos funcionales usados en la Fase 2.

## Terminos

| Termino | Definicion oficial |
| --- | --- |
| Acceso | Intento de ingreso o salida registrado por el sistema en un punto controlado. |
| Evento | Registro tecnico o funcional generado por una accion, lectura, error o decision del sistema. |
| Movimiento | Cambio de estado vehicular asociado con una entrada, una salida o una apertura manual. |
| Entrada | Acceso autorizado o denegado hacia el interior del parqueadero. |
| Salida | Acceso autorizado o denegado hacia el exterior del parqueadero. |
| Autorizacion | Resultado de validar si una persona, vehiculo o TAG cumple las condiciones para acceder. |
| Credencial | Medio de identificacion usado por el sistema para asociar un acceso con un usuario o vehiculo. |
| TAG | Credencial RFID administrada por Cato Parking. |
| EPC | Identificador electronico leido desde un TAG RFID. |
| Vehiculo | Unidad de transporte asociable a una persona usuaria o visitante. |
| Usuario | Persona con relacion institucional o funcional con PUCESA que interactua con el sistema. |
| Propietario | Persona reconocida como responsable principal de un vehiculo registrado. |
| Solicitante | Persona que presenta una solicitud de cupo, TAG o servicio. |
| Visitante | Persona no institucional o temporal cuyo acceso depende de autorizacion especifica. |
| Plaza | Espacio fisico individual disponible para estacionar. |
| Cupo | Derecho o asignacion habilitada para usar una plaza dentro de un periodo o condicion definida. |
| Parqueadero | Area fisica de estacionamiento administrada por el sistema. |
| Espacio reservado | Plaza con uso restringido por regla institucional. |
| Barrera | Dispositivo fisico que controla el paso vehicular. |
| Pluma | Brazo movil de la barrera. |
| Garita | Punto operativo local donde se monitorean accesos y contingencias. |
| Periodo | Ventana temporal oficial para inscripciones, renovaciones o asignaciones. |
| Prioridad | Regla que determina orden preferente de atencion o asignacion. |
| Inscripcion | Proceso mediante el cual una persona solicita o renueva acceso al servicio. |
| Solicitud | Registro formal pendiente de revision o decision. |
| Sancion | Medida institucional aplicada por incumplimiento de una regla aprobada. |
| Incidencia | Situacion anomala, operativa o tecnica que requiere registro o seguimiento. |
| Auditoria | Capacidad de reconstruir que ocurrio, quien actuo y con que resultado. |
| Sincronizacion | Transferencia controlada de informacion entre la aplicacion local y servicios centrales. |
| Operacion offline | Funcionamiento local sin dependencia inmediata de servicios centrales. |

## Criterio de uso

- Este glosario prevalece sobre denominaciones historicas ambiguas.
- Si un termino requiere una nueva acepcion, debe registrarse antes de reutilizarse en requisitos o casos de uso.
