# PR-10 Validacion Financiera

Participantes: Usuario institucional, Analista financiero, Cato Parking.

Flujo principal:
1. Usuario carga comprobante.
2. Financiero revisa evidencia.
3. Aprueba o rechaza.
4. El sistema actualiza el estado de la solicitud.

Alternativas:
- Requerir correccion del comprobante.

Excepciones:
- Tarifa no aprobada.
- Integracion financiera pendiente.

Reglas: RN-PAG-001.  
Casos de uso: CU-PAG-001.
