# C4 Nivel 2 - Contenedores

- Portal web central: sistema externo desde la perspectiva del escritorio.
- Backend/API central: recibe eventos, entrega cambios y administra la verdad central.
- Base de datos central: persistencia institucional.
- Aplicacion local de garita: nodo operativo local.
- Base local de garita: cache operativa y eventos locales.
- Servicio de sincronizacion: capacidad logica entre garita y backend.
- InBIO 260: controlador fisico.
