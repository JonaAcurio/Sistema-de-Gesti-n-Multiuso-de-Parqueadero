# Integracion Microsoft SSO

La garita no autentica contra Microsoft SSO para decidir accesos en tiempo real.

## Relacion con escritorio

- la plataforma central autentica usuarios institucionales con SSO;
- la garita recibe datos operativos ya resueltos por la plataforma;
- el escritorio puede requerir, en una fase posterior, autenticacion local o tecnica separada para operadores.
