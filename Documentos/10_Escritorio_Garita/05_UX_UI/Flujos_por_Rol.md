# Flujos por Rol

## Operador de garita

1. Monitorea accesos.
2. Registra TAG o visitante cuando corresponde.
3. Ejecuta apertura manual justificada en contingencia.
4. Consulta eventos operativos.

## Seguridad

1. Supervisa accesos e incidencias.
2. Valida contingencias.
3. Revisa evidencia para sanciones cuando aplique.

## Financiero

1. Consulta solicitudes con comprobantes.
2. Aprueba o rechaza pagos.
3. Revisa observaciones e historial.

## Soporte tecnico

1. Revisa conectividad y eventos tecnicos.
2. Ejecuta reconexion.
3. Verifica estados posteriores a la contingencia.
