# Casos de Prueba

**Fecha:** 2026-08-10  
**Estado:** Pendiente de materializacion

## Proposito

Aqui deben crearse los artefactos `CP-*` individuales, por ejemplo:

- `CP-CON-001.md`
- `CP-USR-001.md`
- `CP-VEH-001.md`
- `CP-TAG-001.md`
- `CP-ACC-001.md`

## Convencion

Cada archivo de caso de prueba debe incluir como minimo:

- objetivo;
- requisito trazado;
- precondiciones;
- pasos;
- resultado esperado;
- criterio de aprobacion;
- referencia a evidencia ejecutada cuando exista.
