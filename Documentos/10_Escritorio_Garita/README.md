# Documentacion de Escritorio Garita

**Fecha:** 2026-07-18  
**Estado:** Vigente

## Proposito

Esta carpeta concentra la documentacion activa de la aplicacion de escritorio de garita de Cato Parking.

## Alcance

- operacion local de garita;
- conexion y control de hardware;
- lectura de TAG;
- altas basicas de usuarios, vehiculos y TAG;
- control de entradas y salidas;
- reportes operativos;
- cache local y sincronizacion posterior con servicios centrales.

## Separacion respecto a web

- La documentacion web no debe mezclarse con esta carpeta.
- Las normas, requisitos y decisiones de la plataforma web deben vivir en una estructura documental independiente.
- Los documentos aqui presentes solo describen la parte de escritorio y sus fronteras de integracion.
