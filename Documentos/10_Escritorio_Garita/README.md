# Documentacion de Escritorio Garita

**Fecha:** 2026-08-18
**Estado:** Fuente de navegación del corpus activo; validación institucional pendiente

## Proposito

Esta carpeta concentra la documentación activa de la aplicación de escritorio de garita de Cato Parking. Es la entrada oficial del corpus activo dentro de `Documentos/`.

## Alcance

- operacion local de garita;
- conexion y control de hardware;
- lectura de TAG;
- altas basicas de usuarios, vehiculos y TAG;
- control de entradas y salidas;
- reportes operativos;
- caché local y sincronización posterior con servicios centrales.

El contenido distingue prototipo, MVP y sistema completo. Un documento activo en estado de borrador, propuesto o pendiente no equivale a aprobación institucional ni a implementación verificada.

## Separacion respecto a web

- La documentacion web no debe mezclarse con esta carpeta.
- Las normas, requisitos y decisiones de la plataforma web deben vivir en una estructura documental independiente.
- Los documentos aqui presentes solo describen la parte de escritorio y sus fronteras de integracion.
