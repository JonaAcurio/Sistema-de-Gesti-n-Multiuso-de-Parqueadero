# PR-04 Perdida y Reposicion de TAG

Participantes: Usuario institucional, Operador de garita, Administrador funcional, Financiero.

Flujo principal:
1. Usuario reporta perdida.
2. Se desactiva el TAG anterior.
3. Se valida reposicion segun reglas vigentes.
4. Se registra nuevo TAG.
5. Se asocia nuevamente al usuario y vehiculo.

Alternativas:
- Reposicion sin costo si PUCESA lo aprueba.

Excepciones:
- Costo o politica no aprobados.

Reglas: RN-TAG-003, RN-PAG-001.  
Casos de uso: CU-TAG-002, CU-TAG-003.
