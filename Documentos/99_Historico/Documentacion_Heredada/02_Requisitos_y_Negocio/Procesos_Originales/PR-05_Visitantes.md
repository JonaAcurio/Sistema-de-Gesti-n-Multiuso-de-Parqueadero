# PR-05 Ingreso y Salida de Visitante

Participantes: Visitante, Operador de garita, Seguridad, Cato Parking.

Flujo principal:
1. Visitante presenta identificacion.
2. Operador registra datos, vehiculo, motivo y anfitrion.
3. Sistema valida reglas de visita.
4. Se autoriza o deniega ingreso.
5. Se registra permanencia.
6. Se autoriza salida.

Alternativas:
- Visitante institucional con excepcion aprobada.

Excepciones:
- Reglas de visitantes no aprobadas.
- Datos incompletos.

Reglas: RN-VIS-001.  
Casos de uso: CU-VIS-001, CU-VIS-002.
