# PR-09 Gestion de Periodos y Prioridades

Participantes: Administrador funcional, Usuario institucional, Cato Parking.

Flujo principal:
1. Administrador registra periodo.
2. Configura prioridades aprobadas.
3. Publica el periodo.
4. Usuario presenta solicitud.

Alternativas:
- Renovacion de periodo previo.

Excepciones:
- Fechas invalidas.
- Orden de prioridades no aprobado.

Reglas: RN-PER-001, RN-PRI-001.  
Casos de uso: CU-PER-001.
