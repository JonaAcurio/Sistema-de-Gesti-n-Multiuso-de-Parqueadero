- `01_Gestion_Proyecto/`: planificacion, seguimiento y actas.

- `03_Base_de_Datos/`: scripts SQL y estructura del modelo de datos.
- `04_Desarrollo/`: estandares tecnicos y guias de trabajo.
- `05_Operacion/`: manuales operativos y procedimientos de uso (en construccion).

- Crear documentos nuevos en la carpeta tematica correcta.

- Actualizar este indice cuando se agreguen documentos clave.
